Turbo Race website (for GitHub Pages)

Files:
  index.html    game page
  privacy.html  privacy policy (link this in the Amazon listing)
  app-ads.txt   AdMob seller file (must stay in the top folder)
  style.css, img/

Publish (free):
1. Create a GitHub account at github.com (for example username: awfpath).
2. Click "+" > "New repository". Name it exactly: <your-username>.github.io  (e.g. awfpath.github.io). Public. Create.
3. Click "uploading an existing file", drag ALL files and the img folder in, click "Commit changes".
4. Wait 1-2 minutes, then open:
     https://<your-username>.github.io/
     https://<your-username>.github.io/privacy.html
     https://<your-username>.github.io/app-ads.txt
5. Amazon listing: Privacy policy URL = .../privacy.html, Website = https://<your-username>.github.io
6. AdMob: Apps > Turbo Race > App settings > add the same website; AdMob checks app-ads.txt (can take up to 24 h).
